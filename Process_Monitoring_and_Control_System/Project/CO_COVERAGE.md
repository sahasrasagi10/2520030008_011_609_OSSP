# CO1-CO6 Coverage Map

| CO | Implementation in the project |
|---|---|
| CO1 | Shell-like command interface, system calls, fork/exec/wait, Linux/POSIX programming |
| CO2 | Process creation/lifecycle, PID/PPID/state, process control, FCFS scheduling, process group/session information |
| CO3 | Anonymous pipes, internal named FIFO, POSIX signal handler, process-group setup |
| CO4 | /proc memory data, page size/pages, page faults, malloc/free, Copy-on-Write demonstration |
| CO5 | File abstraction, descriptors, open/read/write/close/unlink, stat/inode, buffered/unbuffered I/O, mmap, filesystem information |
| CO6 | POSIX threads, shared task buffer, mutex, condition variable, counting semaphore, thread coordination and cleanup |

The command set is intentionally small. CO concepts are implemented in the code rather than exposed as a separate command for every syllabus topic.
